# Security

## Reporting a vulnerability

Please report security issues **privately** by email to **support@aitalk.ch** with the subject line
"Security". Do not open a public issue.

Include what you found, the version (image tag or commit), and the steps to reproduce it. If you have a
fix or a proof of concept, attach it.

## What to expect

AI Talk is maintained by a small team. We will:

- confirm that we received your report within 5 business days,
- tell you whether we can reproduce it and how we plan to fix it,
- credit you in the release notes if you wish, once a fix is released.

Please give us reasonable time to release a fix before you publish details.

## Supported versions

Security fixes are released for the latest version. Business license and support agreements can include
fixes for older versions.
