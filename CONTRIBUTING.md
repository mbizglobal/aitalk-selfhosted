# Contributing

Thank you for your interest in AI Talk.

**We do not accept code contributions (pull requests) yet.** Accepting outside code needs a contributor
agreement, which we have not set up.

You are welcome to:

- report bugs and suggest improvements as issues,
- report security issues privately as described in [`SECURITY.md`](SECURITY.md),
- modify AI Talk for your own company's use, as the [`LICENSE`](LICENSE) allows.
